Top 3 & 3 counterparty sampling

For each alert, aggregate alerted activity by counterparty across both the originator
and beneficiary sides. Exclude the focal party itself.

Select the three counterparties with the highest cumulative transaction value. Also
select the three counterparties with the highest transaction volume. Break a volume
tie using cumulative transaction value, with the higher value ranked first. Return
the union of both selections, so an alert normally has between three and six sampled
counterparties. If the population contains fewer than three counterparties, select
the entire population.
